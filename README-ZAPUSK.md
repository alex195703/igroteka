# 🎮 Игротека — все игры в одном сайте

Личный игровой портал: **«Сапёр»**, **«Соционический тренажёр»** и **«Сеть магазинов „Браво“»** —
одно Next.js-приложение, один адрес, три игры.

## Что внутри

| Игра | Адрес | Суть |
|------|-------|------|
| 🧨 Сапёр | `#/saper` | Классика: три уровня (9×9, 16×16, 30×16), флажки, рекорды времени |
| 🧠 Соционический тренажёр | `#/socionika` | Раунды по 10 вопросов: типы, дихотомии, функции, квадры, отношения |
| 🏪 Сеть магазинов «Браво» | `#/bravo` | Бизнес-симулятор: найм менеджеров, зарплаты в гривнах по реальному рынку Украины, кризисы, отчёт |

## Запуск на своём компьютере

```bash
bun install        # или npm install
bun run dev        # или npm run dev
```

Откройте http://localhost:3000 — витрина с карточками игр.

## Тест фактологии

```bash
bun scripts/test-bravo.ts    # 6739 автопроверок игры «Браво»
```

Скрипт проверяет таблицу интертипных отношений, пригодность кандидатов,
генерацию рынка, симуляцию кризисов и отчёт. `scripts/calibrate-uah.ts`
сравнивает зарплаты кандидатов с реальным рынком Украины (Work.ua).

## Публикация в интернете (GitHub + Vercel)

1. Создайте репозиторий на https://github.com/new (имя `igroteka`, без README).
2. **Add file → Upload files** → перетащите папки `src` и `scripts` **и** все файлы
   верхнего уровня (`package.json`, `next.config.ts` и др.).
3. На https://vercel.com → **Add New… → Project** → **Import** репозитория → **Deploy**.
4. Через 1–2 минуты сайт получит адрес вида `igroteka-xxx.vercel.app`.

Дальше любое изменение файлов в репозитории автоматически пересобирает сайт.

## Как устроен код

```
src/
├── app/page.tsx            ← витрина + hash-навигация
├── app/layout.tsx          ← метаданные сайта
├── components/
│   ├── saper-game.tsx      ← «Сапёр» (самодостаточный)
│   ├── socionika-trainer.tsx
│   └── bravo-game.tsx      ← интерфейс «Браво»
└── lib/                    ← логика без React:
    ├── bravo.ts            (рынок, кризисы, зарплаты в грн)
    ├── relations.ts        (интертипные отношения)
    ├── socionics-data.ts   (16 типов, квадры, функции)
    └── socionics-quiz.ts   (генератор вопросов викторины)
```

## Два приёма, которые стоит подсмотреть

**Hash-навигация (`#/bravo` вместо `/bravo`).** Портал живёт на одном маршруте `/`,
а «страницы» игр различаются по тому, что стоит в адресе после `#`. Это позволяет
работать и в песочнице (где виден только корень сайта), и на Vercel — без
каких-либо серверных настроек. Адрес меняется, кнопка «назад» браузера работает.

**Прогресс — в браузере игрока.** Ключи localStorage: `saper-best` (рекорды сапёра),
`socionika-best` (рекорды тем), `bravo-game` и `bravo-best` (партия и рекорд «Браво»;
старые ключи `chudo-*` мигрируют автоматически). Сервер и база данных не нужны —
сайт можно бесплатно хостить где угодно.
