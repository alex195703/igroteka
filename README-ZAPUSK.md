# 🎮 Игротека — витрина игр

Личный игровой портал: витрина с карточками и проспектами. Каждая игра живёт
на своём собственном адресе (свой репозиторий → Vercel), поэтому правка одной
игры не трогает витрину и остальные игры, а новая игра добавляется одним
блоком в список `GAMES` в `src/app/page.tsx`.

## Что внутри

| Игра | Адрес | Суть |
|------|-------|------|
| 🧨 Сапёр | [saper-fawn.vercel.app](https://saper-fawn.vercel.app) | Классика: три уровня (9×9, 16×16, 30×16), флажки, «аккорд» профи, рекорды времени |
| 🧠 Соционический тренажёр | [socionika.vercel.app](https://socionika.vercel.app) | Викторина по 16 типам: дихотомии, функции и модель А, квадры, интертипные отношения |
| 🏪 Пульс сети («Браво») | [bravo-amber.vercel.app](https://bravo-amber.vercel.app) | Бизнес-симулятор: сеть магазинов, найм по соционике, зарплаты в гривнах по реальному рынку Украины, кризисы, отчёт |
| 🏛️ Виртуальное министерство | [vsrtualne-ministersnvo.vercel.app](https://vsrtualne-ministersnvo.vercel.app) | Политический симулятор: реальные кабмины Украины 2005–2026 прогнаны через алгоритм «Пульса сети»; соберите свой Кабмин и встаньте в рейтинг с историей |

## Как добавить новую игру

1. Опубликуйте игру: свой репозиторий на GitHub → Vercel → Deploy.
2. В `src/app/page.tsx` допишите блок в список `GAMES`: карточка (emoji, title,
   desc, url, цвета) + проспект (blocks или short). Подробная инструкция —
   в шапке файла.
3. Обновите метаданные в `src/app/layout.tsx` и таблицу выше.

## Запуск на своём компьютере

```bash
bun install        # или npm install
bun run dev        # или npm run dev
```

Откройте http://localhost:3000 — витрина с карточками игр.

## Тест фактологии

```bash
bun scripts/test-bravo.ts    # 6739 автопроверок игры «Браво»
```

Скрипт проверяет таблицу интертипных отношений, пригодность кандидатов,
генерацию рынка, симуляцию кризисов и отчёт. `scripts/calibrate-uah.ts`
сравнивает зарплаты кандидатов с реальным рынком Украины (Work.ua).

## Публикация в интернете (GitHub + Vercel)

1. Создайте репозиторий на https://github.com/new (имя `igroteka`, без README).
2. **Add file → Upload files** → перетащите папки `src` и `scripts` **и** все файлы
   верхнего уровня (`package.json`, `next.config.ts` и др.).
3. На https://vercel.com → **Add New… → Project** → **Import** репозитория → **Deploy**.
4. Через 1–2 минуты сайт получит адрес вида `igroteka-xxx.vercel.app`.

Дальше любое изменение файлов в репозитории автоматически пересобирает сайт.

## Как устроен код

```
src/
├── app/page.tsx            ← витрина: список GAMES (карточки + проспекты)
├── app/layout.tsx          ← метаданные сайта
└── lib/                    ← библиотеки без React:
    ├── bravo.ts            (рынок, кризисы, зарплаты в грн — эталон игры «Браво»)
    ├── relations.ts        (интертипные отношения)
    ├── socionics-data.ts   (16 типов, квадры, функции)
    └── socionics-quiz.ts   (генератор вопросов викторины)
src/components/             ← ранние встроенные версии игр; сейчас каждая
                              игра живёт на своём адресе, папка оставлена
                              для истории и локального запуска
```

**Прогресс — в браузере игрока.** Ключи localStorage: `saper-best` (рекорды
сапёра), `socionika-best` (рекорды тем), `bravo-game` и `bravo-best` (партия и
рекорд «Браво»), `vm-builder-v1` (собранный кабинет «Виртуального министерства»).
Сервер и база данных не нужны — сайт можно бесплатно хостить где угодно.
